# পড়াশালা — বাংলা ছোট প্রশ্নের পরীক্ষা

বাংলায় ছোট প্রশ্নের উত্তর লিখে পরীক্ষা নেওয়ার জন্য একটি সুন্দর, responsive, registration-free ওয়েব অ্যাপ। এটি GitHub Pages-এ সরাসরি চালানো যায়; কোনো build step বা backend প্রয়োজন হয় না।

## চালু করুন

`index.html` ফাইলটি ব্রাউজারে খুলুন, অথবা GitHub repository-তে **Settings → Pages** থেকে `main` branch-এর root নির্বাচন করে GitHub Pages চালু করুন।

## ফিচার

- পরীক্ষা, বিষয়, তারিখ, অধ্যায় এবং এক বা একাধিক ছোট প্রশ্ন যোগ করা।
- নমুনা উত্তর ঐচ্ছিক—প্রশ্নমাত্র বা প্রশ্নের সঙ্গে উত্তরসূচি, দুটোই করা যায়।
- পরীক্ষার্থী নিবন্ধন ছাড়াই যেকোনো সংখ্যক উত্তর লিখে, কিছু বা সব প্রশ্ন ফাঁকা রেখে জমা দিতে পারে।
- জমা দেওয়ার পরে উত্তর করা/ফাঁকা রাখা প্রশ্নের সংখ্যা এবং যোগ করা নমুনা উত্তর দেখা যায়। ছোট উত্তরের মান বিচার স্বয়ংক্রিয় নয়; এটি উত্তর করা প্রশ্নের সংখ্যা গোনে।
- পরীক্ষা ও বিষয় দিয়ে খোঁজা, বিষয় অনুযায়ী ফিল্টার করা এবং পুরোনো পরীক্ষা আবার দেওয়া।
- `.txt` ফাইল থেকে পরীক্ষার তথ্য ও প্রশ্ন আমদানি, এবং সব পরীক্ষা `.json` ফাইলে রপ্তানি/আবার আমদানি।
- মোবাইল ও ডেস্কটপ উপযোগী রঙিন নকশা।

## `.txt` ফাইলের ফরম্যাট

`sample-exams.txt` নমুনা দেখুন। বাংলা/ইংরেজি অঙ্কে প্রশ্ন নম্বর দেওয়া যায়। একটি প্রশ্ন এক লাইনে লিখুন, আর তার পরের লাইনে ঐচ্ছিক `উত্তর:` যোগ করুন। তারিখ `YYYY-MM-DD` ফরম্যাটে দিলে সবচেয়ে নির্ভরযোগ্যভাবে কাজ করবে।

```text
পরীক্ষার নাম: বাংলা ভাষা ও সাহিত্য
বিষয়: বাংলা
তারিখ: 2026-11-20
অধ্যায়: ভাষা আন্দোলন

প্রশ্ন:
১. ভাষা আন্দোলন কত সালে হয়েছিল?
উত্তর: ১৯৫২ সালে।
২. আন্তর্জাতিক মাতৃভাষা দিবস কবে?
```

অ্যাডমিন ফর্মে ফাইল বেছে নেওয়ার পর তথ্যগুলো সম্পাদনা করে **পরীক্ষা সংরক্ষণ** চাপুন।

## ডেটা কোথায় থাকে — গুরুত্বপূর্ণ

এই সংস্করণটি সম্পূর্ণ static, তাই পরীক্ষা ও উত্তরসূচি **যে ব্রাউজারে তৈরি করা হয় সেই ব্রাউজারের local storage-এ** থাকে। এটি স্বয়ংক্রিয়ভাবে অন্য পরীক্ষার্থী বা ডিভাইসের সঙ্গে ডেটা শেয়ার করে না; ব্রাউজারের ডেটা মুছে গেলে সংরক্ষিত পরীক্ষাও মুছে যেতে পারে। অন্য ডিভাইসে পরীক্ষাগুলো নিতে **ডেটা রপ্তানি** করে JSON ফাইলটি সেখানে **ডেটা আমদানি** করুন।

যদি অ্যাডমিনের যোগ করা পরীক্ষা ইন্টারনেটের সব ব্যবহারকারীর কাছে সঙ্গে সঙ্গে দেখাতে হয়, তাহলে Firebase/Supabase-এর মতো shared database, authentication/নিরাপদ admin access এবং hosting-এ backend configuration যোগ করতে হবে। শুধু GitHub Pages বা browser storage দিয়ে সেই cross-device publishing সম্ভব নয়।

## গোপনীয়তা

পরীক্ষার্থীর উত্তর সার্ভারে পাঠানো বা স্থায়ীভাবে সংরক্ষণ করা হয় না। ফলাফল জমা দেওয়ার পর একই ব্রাউজার সেশনে দেখানো হয়। ওয়েব ফন্ট লোড হলে Google Fonts-এর সঙ্গে সংযোগ হয়; ইন্টারনেট না থাকলেও অ্যাপের মূল কার্যকারিতা থাকে।
